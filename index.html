    Dokumentasi Auto Sender

    ✅ Penjelasan langkah-langkah (versi lebih lengkap):

    1. StarBox mengirim POST ke URL Sumber Pesan Pending (jika Anda hanya memasukkan domain, sistem otomatis menambahkan /schedule/getpendingmessage) dengan payload uid & service.
    2. StarBox membuka WhatsApp Web dan masuk ke chat nomor tujuan sesuai respons.
    3. StarBox mensimulasikan tindakan manusia: mengetik, klik kirim, dan jeda antar pesan (anti-ban).
    4. Setelah terkirim, StarBox mengirim laporan status ke URL Callback (opsional) (fungsi resolver menambahkan /schedule/updatestatusmessage bila Anda tidak menyediakan path lengkap).
    5. Monitor menampilkan antrian, log proses, status kirim, dan statistik real-time.

    📌 Format respons API (server → StarBox): 

    {
  "data": [
    {
      "id": "msg-id",
      "phone": "628123456789",
      "message": "Hello world",
      "priority": 0
    }
  ]
}

    Catatan:
    - priority menentukan urutan (default 0 jika kosong).
    - phone dapat diawali +62 atau 628....
    - message bisa teks, emoji, atau multiline.

    📡 Payload yang dikirim StarBox saat fetch: 

    {
  "uid": "device-uid",
  "service": "whatsapp",
  "services": "whatsapp"
}

    📮 Format callback (StarBox → server): 

    {
  "status": "done",
  "id": "msg-id",
  "error_message": ""
}
    {
  "status": "failed",
  "id": "msg-id",
  "error_message": "Nomor tidak ditemukan / WA offline"
}

    Tutorial Koneksi ADB

    Langkah singkat menyalakan Developer Options, USB Debugging, dan Debugging nirkabel untuk dipakai di StarBox (Android/iOS page).

    1) Aktifkan Developer Options

    1. Buka Settings → About Phone.
    2. Ketuk Build Number 7x sampai muncul pesan pengembang aktif.
    3. Masukkan PIN jika diminta.

    2) Aktifkan USB Debugging

    1. Buka Settings → Developer Options (kadang di Sistem → Lanjutan).
    2. Nyalakan USB Debugging dan konfirmasi OK.

    Setelah aktif, sambungkan HP via kabel lalu klik Refresh ADB di dialog Tambah Android.

    3) Debugging Nirkabel (opsional)

    1. Nyalakan Wireless Debugging.
    2. Pastikan HP dan PC di WiFi yang sama.
    3. Pilih Pair device with pairing code lalu jalankan: 
    adb pair ip:port
adb connect ip:port

    Catatan Vendor

    • Xiaomi / Redmi / POCO: aktifkan juga USB Debugging (Security Settings) di Developer Options (butuh akun Mi).
    • Samsung: Build Number ada di Settings → About phone → Software Information.

    Jika Wireless Debugging belum terdeteksi (terutama di Mac), pastikan firewall mati atau izinkan adb melewati firewall, lalu ulangi pair/connect.
