About StarBox

StarBox dikembangkan oleh Gingin Abdul Goni.

StarBox adalah pusat kendali emulator multi-platform — Android, iOS, dan layanan desktop — yang membantu Anda mengelola WhatsApp, Shopee, Telegram, dan automation tools lainnya dalam satu dashboard. Fokus pada produktivitas, biar StarBox yang mengurus sisanya.

    Dokumentasi Auto Sender

    ✅ Penjelasan langkah-langkah (versi lebih lengkap):

    1. StarBox mengirim POST ke URL Sumber Pesan Pending (jika Anda hanya memasukkan domain, sistem otomatis menambahkan /schedule/getpendingmessage) dengan payload uid & service.
    2. StarBox membuka WhatsApp Web dan masuk ke chat nomor tujuan sesuai respons.
    3. StarBox mensimulasikan tindakan manusia: mengetik, klik kirim, dan jeda antar pesan (anti-ban).
    4. Setelah terkirim, StarBox mengirim laporan status ke URL Callback (opsional) (fungsi resolver menambahkan /schedule/updatestatusmessage bila Anda tidak menyediakan path lengkap).
    5. Monitor menampilkan antrian, log proses, status kirim, dan statistik real-time.

    📌 Format respons API (server → StarBox):

    {
  "data": [
    {
      "id": "msg-id",
      "phone": "628123456789",
      "message": "Hello world",
      "priority": 0
    }
  ]
}

    Catatan:
    - priority menentukan urutan (default 0 jika kosong).
    - phone dapat diawali +62 atau 628....
    - message bisa teks, emoji, atau multiline.

    📡 Payload yang dikirim StarBox saat fetch:

    {
  "uid": "device-uid",
  "service": "whatsapp",
  "services": "whatsapp"
}

    📮 Format callback (StarBox → server):

    {
  "status": "success",
  "message_id": "msg-id",
  "error_message": ""
}
    {
  "status": "failed",
  "message_id": "msg-id",
  "error_message": "Nomor tidak ditemukan / WA offline"
}
