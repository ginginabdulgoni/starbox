Tutorial Koneksi ADB

Langkah singkat menyalakan Developer Options, USB Debugging, dan Debugging nirkabel untuk dipakai di StarBox (Android/iOS page).

1) Aktifkan Developer Options

  1. Buka Settings → About Phone.
  2. Ketuk Build Number 7x sampai muncul pesan pengembang aktif.
  3. Masukkan PIN jika diminta.

2) Aktifkan USB Debugging

  1. Buka Settings → Developer Options (kadang di Sistem → Lanjutan).
  2. Nyalakan USB Debugging dan konfirmasi OK.

Setelah aktif, sambungkan HP via kabel lalu klik Refresh ADB di dialog Tambah Android.

3) Debugging Nirkabel (opsional)

  1. Nyalakan Wireless Debugging.
  2. Pastikan HP dan PC di WiFi yang sama.
  3. Pilih Pair device with pairing code lalu jalankan: 
adb pair ip:port
adb connect ip:port

Catatan Vendor

  • Xiaomi / Redmi / POCO: aktifkan juga USB Debugging (Security Settings) di Developer Options (butuh akun Mi).
  • Samsung: Build Number ada di Settings → About phone → Software Information.

Jika Wireless Debugging belum terdeteksi (terutama di Mac), pastikan firewall mati atau izinkan adb melewati firewall, lalu ulangi pair/connect.
